# Devin limits

A thin full-width strip at the bottom of the window that shows Devin CLI Pro plan
usage in one line: daily and weekly quota windows, each as a bar, percent used and
the time left until it resets, followed by the current overage balance.

## What you see

One block docked at the bottom of the layout, 26px tall, full window width, `chrome`
background with a 1px `border` line on top. One line of text in the app's UI font
at the UI text size (`settings().ui_font_size`, 13px by default), 14px padding left and right, vertically
centered:

```
<logo> ━━━━━ 37% 4h 27m · ━━━━━ 18% 2d 2h · $7.08
```

- `<logo>` is the Devin symbol (`devin.svg`, drawn with `svg(...)` at 0.85 × the text
  size, tinted `muted`). The daily window comes first, then the weekly one, with no
  labels; a `dim` `·` separates them. The percent and time left are `foreground`.
- The bar is 48px wide and 6px tall, fully rounded: a `border`-colored track with a
  `muted` (grey) fill equal to the used percent. From 80% the fill and percent are
  both `ansi3` (yellow), from 95% `ansi1` (red).
- Spacing is 8px between the logo, windows and separators, and 6px inside a window.
- Time left until reset: `48m` under an hour, `4h 48m` under a day, else `2d 2h`.
- When the overage balance is positive, a `dim` `·` and its dollar value, rounded to
  two decimal places, follow the windows.
- No data yet: `<logo> …`. Missing or rejected credentials: `<logo> not signed in`;
  no quota billing or no visible window: `<logo> no quota`; other failure:
  `<logo> unavailable`.
- Stale (the last fetch failed but older values exist): the whole line at 50% opacity,
  followed by `· stale <age>` in `dim` (`12m`, `3h`, `2d`).

## How it behaves

- No agent statuses: it shows account quota data, not agents.
- Fetches on start, then every 5 minutes, and 15 s after any shown window's reset time.
- Click anywhere on the strip: fetch now. Only one fetch runs at a time; a click during
  one starts no second fetch. From the click until that fetch ends, the line is at 30%
  opacity. If it fails, `· update failed` follows in `dim` until the next fetch ends.
  Background fetches don't dim the line.
- A failed fetch keeps the last good values (stale) and retries after 1 minute,
  doubling up to 5 minutes; a success resets the backoff.
- A window whose reset time has passed disappears until the next fetch brings it back.
- The line redraws once a minute (stale age, expiry, time left), after each fetch and
  on a click; apart from the click's dim nothing animates.
- The last good values persist across reloads and restarts in shared state.

## Built from

- No layout: one mod, `mods/devin-limits/`, with `mod.json`
  `{ "place": "bottom", "size": 26 }` so the app docks it under the shown layout the
  first time it sees the folder. No props.
- `main.js`: a `View` with `init` (reads `shared("devin-limits")`, starts
  `cx.timer.every(5000)` and a first fetch) and `render`. Uses `exec`, `appHome`,
  `theme`, `settings`, `shared`, `setShared` from `herdr`, `div` and `svg` from `gpui-kit`,
  `h_flex` from `gpui-base`. The fetch runs
  `exec("python3", [appHome() + "/mods/devin-limits/devin_limits.py"], { timeout: 25000 })`
  inside `cx.spawn`. Shared key `devin-limits` holds `{ windows, overageMicros, fetchedAt }`
  with `fetchedAt` in milliseconds.
- `devin_limits.py` (Python 3.11 standard library): reads the Devin credentials TOML
  and posts a `GetUserStatus` request to the configured API server. It prints exactly
  one line: `{"windows":{"day":{"usedPercent","resetsAt"},...},"overageMicros",
  "plan","fetchedAt"}` or `{"error":"not_signed_in"|"no_quota"|"timeout"|"failed",
  "detail"}`. Reset timestamps are Unix seconds; missing remaining percentages mean
  0% remaining.
- Credentials come from `$DEVIN_CREDENTIALS`, else
  `~/.local/share/devin/credentials.toml`; the API server defaults to
  `https://server.codeium.com`.
- Art: `devin.svg`, the Devin mark as one path, drawn with `svg(...)` so it takes the
  text color.

## Watch out

- Send nothing to stderr and nothing but the one JSON line to stdout. Error details
  are limited to 200 characters and never include the API key.
- The helper treats omitted proto3 values as zero: missing quota remaining means
  100% used, and missing overage means zero.
- Hidden quota windows and windows without a valid reset time are omitted by the
  helper; `main.js` hides windows whose reset time has passed.
  If no usable window remains, the helper reports `no_quota`.
- `herdr-app check` writes `gpui-kit.d.ts` and `jsconfig.json` into the mod folder;
  they are generated by the app, not part of the mod.
- The app docks the strip into whichever layout is shown at install time (when it first
  sees the folder); other layouts don't get the strip.
- A copy keeps polling while hidden; the 5 s tick only compares times and redraws once
  a minute.

## Done when

- `python3 -m unittest discover -s tests -v` passes for successful responses, hidden
  and absent fields, malformed or missing credentials, authentication and server
  errors, invalid JSON, timeouts, and connection failures.
- Running the helper by hand prints one JSON line with the account's day and week
  windows and overage balance.
- `herdr-app check mods/devin-limits` passes.
- The strip shows the windows and positive overage balance at the bottom of the window.
